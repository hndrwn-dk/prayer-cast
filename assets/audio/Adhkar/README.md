# Adhkar Audio Files

This directory contains the audio recitations for morning and evening adhkar.

## Required Files

- `adhkar_morning.mpeg` - Morning adhkar recitation (after Fajr)
- `adhkar_evening.mpeg` - Evening adhkar recitation (after Asr)

## File Details

- Format: MPEG audio
- Morning file size: ~20 MB
- Evening file size: ~26 MB

## Usage

These files are loaded and cast to the home speaker when the user has enabled morning/evening adhkar reminders.

## Source

Audio files sourced from authentic Islamic adhkar recitations.
